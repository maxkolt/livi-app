# Capacity calculator — оценка нод на 10k concurrent

Заполняй после прогонов Stage B/C реальными метриками. Точное число нод зависит от битрейта, доли TURN, кодека и профиля устройств.

---

## Исходные допущения (подставь свои)

| Параметр | Значение | Комментарий |
|----------|----------|-------------|
| Целевой concurrent users | 10 000 | ≈ 5 000 звонков 1:1 |
| Средний битрейт на участника (исходящий с SFU) | _______ kbps | Из метрик или профиля (poor/mid/high). |
| Доля трафика через TURN | _______ % | Критично для нагрузки на TURN и сеть. |
| Целевая загрузка одной SFU-ноды (participants) | _______ | Из Stage A/B: при какой нагрузке CPU < 70% и SLO держатся. |

---

## Битраты по плану (для подстановки)

| Профиль | Битрейт | Когда использовать |
|---------|---------|--------------------|
| poor | 300–500 kbps | Плохая сеть |
| mid | 700–1200 kbps | Обычный default (720p) |
| high | 1500–2500 kbps | Хорошая сеть, адаптивно |

Средний битрейт для расчёта можно взять как средневзвешенный по доле пользователей в каждом профиле (например 20% poor, 60% mid, 20% high).

---

## Формула (упрощённо)

```
required_sfu_nodes = ceil(10_000 / participants_per_node)
participants_per_node = из прогона (макс. при соблюдении SLO и CPU < 70%)
```

Учёт TURN:
- TURN не на SFU: отдельный пул, считай ноды TURN по своему лимиту соединений/пропускной способности.
- Суммарный исходящий трафик SFU: `10_000 * avg_bitrate_kbps * 2` (приём + отправка в 1:1) — для оценки NIC/сети.

---

## Сеть (ориентир)

Для 10k при среднем 1 Mbps на участника (1:1, два потока на участника):
- Порядок: 10k * 1 * 2 ≈ **20 Gbps** суммарно (упрощённо). Реально меньше за счёт dynacast/adaptive и не всех одновременно в пике.
- NIC на одну SFU: (total_Gbps / number_of_nodes) + запас.

---

## Что подставить из прогонов

1. **Stage A/B:** макс. participants на одну ноду при P95 join < 2.5s, CPU < 70% → **participants_per_node**.
2. **Метрики TURN:** % участников с TURN relay → доля для расчёта пула TURN.
3. **Битрейт:** из LiveKit/дашбордов средний исходящий на участника → **avg_bitrate_kbps**.

После заполнения таблицы получишь оценку числа SFU-нод и объёма сети для 10k.
