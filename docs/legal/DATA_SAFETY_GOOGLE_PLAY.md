# Google Play Console — декларации LiVi

Чеклист для **Play Console → Контент приложения**. Ответы должны совпадать с политикой
`docs/index.html` (публикуется на https://maxkolt.github.io/livi-app/). Обновлено 20.11.2026.

Это рабочая карта для сверки, а не подтверждение ответов, уже отправленных в Play Console.
Перед отправкой нужно проверить фактические потоки данных приложения, backend и включённых
SDK в конкретной релизной сборке. Таблицу ниже необходимо дополнить всеми применимыми
типами данных: в частности, проверить идентификаторы пользователей, социальные связи и
историю звонков, видеосообщения и внутренние текстовые отзывы.

## Безопасность данных (Data safety)

Приложение **собирает** и **передаёт** данные. Шифрование при передаче — **да** (HTTPS/WSS).
Удаление — **да**: в приложении (Профиль → Удалить профиль) и по ссылке выше.

| Тип данных | Собирается | Передаётся третьим лицам | Обязательно | Цели |
|---|---|---|---|---|
| Личная информация → Имя (никнейм) | Да | Нет | Да | Функции приложения, управление аккаунтом |
| Фото и видео → Фото (аватар, фото в чатах) | Да | Нет | Нет | Функции приложения |
| Фото и видео → Видео (кадры случайного чата для модерации) | Да | Да (Google Cloud Vision) | Да | Безопасность, соответствие требованиям |
| Аудио → Голосовые сообщения | Да | Нет | Нет | Функции приложения |
| Сообщения → Другие сообщения в приложении | Да | Нет | Нет | Функции приложения |
| Действия в приложении → Взаимодействие с приложением | Да | Да (Firebase Analytics, AppMetrica) | Да | Аналитика |
| Сведения о работе приложения → Журналы сбоев, диагностика | Да | Да (Crashlytics, AppMetrica) | Да | Аналитика |
| Идентификаторы устройства или другие идентификаторы | Да | Да (Firebase, AppMetrica) | Да | Функции приложения, аналитика, безопасность |

Отсутствие записи звонка само по себе не освобождает от декларации. По
[инструкции Google для Data safety](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)
сбором считается передача данных с устройства. Если данные обрабатываются только в памяти
и не дольше, чем нужно для конкретного запроса в реальном времени, их следует включить в
ответы формы и отметить как обрабатываемые временно (`ephemeral`); такие данные могут не
показываться в публичном разделе Data safety.

Отдельное исключение действует для действительно сквозного шифрования: данные должны
быть недоступны всем посредникам, включая разработчика, а ключи — только отправителю
и получателю. HTTPS/WSS и отсутствие записи не равнозначны этому исключению. Для аудио,
видео и сообщений каждого режима, включая случайный чат и кадры модерации, нужно
отдельно подтвердить фактическую обработку и применимость исключения. Передачу SDK и
поставщикам услуг также следует сверить с определениями сбора и передачи Google;
техническое участие стороннего сервиса не всегда означает `sharing` в терминах формы.

## Другие декларации

- **Рекламный идентификатор (Advertising ID):** «Да, использует» — его читают Firebase Analytics и
  AppMetrica (разрешение `com.google.android.gms.permission.AD_ID` приходит из SDK). Цель — аналитика.
  Реклама в приложении: **нет**.
- **Полноэкранные уведомления (`USE_FULL_SCREEN_INTENT`):** категория «Звонки» — входящий видеозвонок.
- **Фоновые сервисы (Foreground service):** для каждого типа нужно короткое видео:
  - `phoneCall` — входящий и активный звонок (IncomingCallForegroundService, ActiveCallForegroundService);
  - `microphone` — микрофон во время звонка в фоне и в PiP;
  - `mediaPlayback` — гудки исходящего вызова (LiviOutgoingCallService);
  - `specialUse` — показ экрана входящего вызова поверх других приложений (IncomingCallForegroundService).
- **Целевая аудитория:** только 18+. Детям приложение не адресовано.
- **Ограничение доступа несовершеннолетних:** проверить включение `Restrict Minor Access`
  в Play Console. [Политика Google](https://support.google.com/googleplay/android-developer/answer/16302250?hl=en)
  прямо относит приложения случайного общения с незнакомыми людьми к приложениям,
  которые должны использовать инструменты Play Console для блокирования доступа
  несовершеннолетних. Указание «18+» в политике или возрастной рейтинг сами по себе
  не подтверждают включение этой настройки.
- **Возрастной рейтинг (IARC):** пользователи общаются друг с другом, есть обмен фото, случайный видеочат.
- **Правительственные приложения, финансы, здоровье:** нет.
