## Безопасность данных (Data safety)

Приложение **собирает** и **передаёт** данные. Шифрование при передаче — **да** (HTTPS/WSS).
Удаление — **да**: в приложении (Профиль → Удалить профиль) и по ссылке выше.

| Тип данных | Собирается | Передаётся третьим лицам | Обязательно | Цели |
|---|---|---|---|---|
| Личная информация → Имя (никнейм) | Да | Нет | Да | Функции приложения, управление аккаунтом |
| Фото и видео → Фото (аватар, фото в чатах) | Да | Нет | Нет | Функции приложения |
| Фото и видео → Видео (кадры случайного чата для модерации) | Да | Да (Google Cloud Vision) | Да | Безопасность, соответствие требованиям |
| Аудио → Голосовые сообщения | Да | Нет | Нет | Функции приложения |
| Сообщения → Другие сообщения в приложении | Да | Нет | Нет | Функции приложения |
| Действия в приложении → Взаимодействие с приложением | Да | Да (Firebase Analytics, AppMetrica) | Да | Аналитика |
| Сведения о работе приложения → Журналы сбоев, диагностика | Да | Да (Crashlytics, AppMetrica) | Да | Аналитика |
| Идентификаторы устройства или другие идентификаторы | Да | Да (Firebase, AppMetrica) | Да | Функции приложения, аналитика, безопасность |

Звук и видео звонков идут через сервер в реальном времени и не записываются — отдельно как
«собираемые» их не отмечаем, кроме кадров модерации выше.

## Другие декларации

- **Рекламный идентификатор (Advertising ID):** «Да, использует» — его читают Firebase Analytics и
  AppMetrica (разрешение `com.google.android.gms.permission.AD_ID` приходит из SDK). Цель — аналитика.
  Реклама в приложении: **нет**.
- **Полноэкранные уведомления (`USE_FULL_SCREEN_INTENT`):** категория «Звонки» — входящий видеозвонок.
- **Фоновые сервисы (Foreground service):** для каждого типа нужно короткое видео:
  - `phoneCall` — входящий и активный звонок (IncomingCallForegroundService, ActiveCallForegroundService);
  - `microphone` — микрофон во время звонка в фоне и в PiP;
  - `mediaPlayback` — гудки исходящего вызова (LiviOutgoingCallService);
  - `specialUse` — показ экрана входящего вызова поверх других приложений (IncomingCallForegroundService).
- **Целевая аудитория:** только 18+. Детям приложение не адресовано.
- **Возрастной рейтинг (IARC):** пользователи общаются друг с другом, есть обмен фото, случайный видеочат.
- **Правительственные приложения, финансы, здоровье:** нет.
