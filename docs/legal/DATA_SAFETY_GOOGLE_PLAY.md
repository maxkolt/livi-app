# Декларация «Безопасность данных» (Google Play) — LiVi

Используйте этот чеклист в **Play Console → Контент приложения → Безопасность данных**.  
Отклонение по **versionCode 123**: не заявлен тип **«Идентификаторы устройства или другие идентификаторы»**.

## 1. Собирает ли приложение данные?

**Да**, приложение собирает и передаёт данные.

## 2. Обязательно: «Идентификаторы устройства или другие идентификаторы»

В коде LiVi используются (см. `frontend/utils/installId.ts`, `frontend/utils/pushNotifications.ts`, backend `Install` / push):

| Что | Зачем |
|-----|--------|
| Идентификатор установки (`installId`, на Android часто на основе **Android ID**) | Привязка профиля, сокеты, API (`x-install-id`) |
| **FCM-токен** (идентификатор для push) | Входящие звонки и уведомления |
| Внутренний **userId** | Аккаунт, чаты, звонки |
| Токены Expo push (если применимо) | Доставка уведомлений |

**В форме Google Play для этого типа данных укажите:**

- **Собираются** — Да  
- **Передаются третьим лицам** — Да (см. п. 4)  
- **Обработка обязательна** — Да (без этого не работают вход, push, звонки)  
- **Цели** (отметьте подходящие):
  - **Функции приложения**
  - **Управление аккаунтом** (если есть в списке)
  - **Сообщения разработчика** / доставка уведомлений (push)
  - **Аналитика** — только если в декларации включены Firebase Analytics / телеметрия из `LiviAppModule` (Crashlytics/Analytics)
  - **Предотвращение мошенничества, безопасность и соответствие** — по желанию, если используете для rate limit / модерации

**Шифрование при передаче:** Да (HTTPS / WSS к вашему серверу).

**Можно ли запросить удаление:** Да — если в приложении или по запросу в поддержку удаляете аккаунт/данные (укажите так же, как в политике).

## 3. Рекомендуется также заявить (чтобы не было следующих отклонений)

Сверьте с фактическим функционалом и отметьте в форме:

| Тип в Play Console | LiVi |
|--------------------|------|
| **Личная информация** → Имя / никнейм | Профиль |
| **Фото и видео** | Аватар, вложения в чате, видеозвонки |
| **Аудиофайлы** | Голос/звук в звонках (если спрашивают отдельно) |
| **Сообщения** / пользовательский контент | Чаты, медиа |
| **Действия в приложении** | Только если включаете аналитику событий |

Для каждого типа: **собирается**, цель **функции приложения**, передача **на ваш сервер**; для медиа/сообщений — не для рекламы.

## 4. Третьи стороны (передача данных)

Укажите **поставщиков услуг**, которым могут уходить идентификаторы или технические данные:

| Сервис | Данные | Цель |
|--------|--------|------|
| **Google Firebase** (FCM, при необходимости Analytics / Crashlytics) | FCM-токен, технические идентификаторы, события сбоев | Push, стабильность |
| **Ваш backend** (LiVi API) | installId, userId, push-токены, контент чатов | Работа приложения |
| **LiveKit** (если используете облако LiveKit) | userId / identity в токене комнаты | Видеозвонки |

В разделе «Передаются ли данные третьим лицам» — **Да**, с уточнением: **обработчики по договору**, не продажа данных.

## 5. Политика конфиденциальности

URL в Play Console должен совпадать с опубликованной политикой (например `https://maxkolt.github.io/livi-app/`).  
После правок в `docs/index.html` **опубликуйте** страницу на GitHub Pages, иначе расхождение с декларацией останется.

## 6. После заполнения формы

1. Сохранить декларацию.  
2. Отправить изменения на проверку (или новый релиз с **versionCode ≥ 124**, если требуется новая сборка).  
3. В отклонении выбрать **«Обновить декларацию»**, если Google предлагает только правку формы без нового APK.

---

*Справочно: автоматическая проверка Google сопоставляет APK/SDK (Firebase Messaging, Analytics, Crashlytics) с вашей декларацией.*
