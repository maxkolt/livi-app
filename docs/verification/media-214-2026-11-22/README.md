# Проверка медиа Android 214 — 22 ноября 2026

В 213 / 1.1.22 на S25 Ultra подтверждены HTTP 401 при загрузке вложений.
Серверная защита файлов требует авторизацию, которой нет в медиазагрузчиках 213.

В 214 защищённая загрузка уже существовала, но физическая проверка выявила
отдельный дефект первого запуска видеокружка: плеер создавался с пустым источником,
а замена источника после скачивания освобождала shared object до привязки Android View.
В логе: `Cannot set prop 'player'` / `Cannot use shared object that was already released`.
Теперь загрузка завершается перед созданием плеера; локальный URI задаёт отдельный
экземпляр компонента. Добавлен регрессионный тест ожидания загрузки.

## Физические проверки

Использовался отдельный пакет `com.kolt12max.livi.qa214media` с release-кодом,
`BuildConfig.DEBUG=false` и разрешённой инструментализацией для подготовки
двух собственных тестовых аккаунтов; отдельный временный профиль использовался
для последующих уточнений геометрии. Основные приложения 213 и их данные
не удалялись и не обновлялись. Обновление Play 213 → 214 поверх пользовательского
аккаунта не проверялось: сертификат установленной версии отличается от локального.
QA APK на момент физической приёмки содержал тот же Hermes bundle, что и AAB
того этапа. Последующие небольшие визуальные уточнения собраны в итоговый AAB
без повторной установки QA-пакетов на устройства.

- A35, Wi-Fi без VPN: старые и зашифрованные фото показаны в чате;
  зашифрованное фото открыто в полноэкранном просмотрщике.
- Старые и зашифрованные голосовые: прогресс воспроизведения и Android AudioTrack,
  для пятисекундного WAV подтверждены 120000 доставленных PCM-кадров.
- Старый видеокружок воспроизведён. Зашифрованный кружок после удаления QA-кэша
  запущен первым тапом: зафиксированы разные цветовые кадры и изменение прогресса.
  Ошибка освобождённого объекта после исправления не повторилась.
- Все 6 скачанных/расшифрованных файлов A35 совпали по SHA-256 с оригиналами.
- S25 Ultra, Wi-Fi через уже включённый Privata VPN: фото, голосовое и первый
  запуск зашифрованного кружка проверены; сохранены разные кадры видео.
  Пять загруженных файлов совпали с оригиналами по SHA-256.
- Анонимный HTTP-доступ ко всем шести тестовым вложениям отклонён с 401.
- Слышимость из динамиков человеком не подтверждена: вопрос пользователю задан,
  ответа на момент фиксации не было. Синтетическое видео не содержит звуковой дорожки.
- Privata на A35 отсутствует; HIRO не включался. VPN/сеть S25 не переключались.
  Смена маршрута во время воспроизведения не проверялась.

## Поиск: блок «Онлайн»

По уточнению пользователя уменьшение высоты применяется только к большим телефонам
того же класса, что S25 Ultra: используется существующий `usesLargePhoneAvatar`,
исключающий A35 при любом display zoom. В портрете A35 сохраняет 78 dp,
S25 Ultra получает 68 dp (последнее уточнение: 64 → 68 dp). Верхний отступ обоих телефонов увеличен на 4 dp: 10 → 14 dp.
На больших телефонах боковые поля панели уменьшены с 12 до 8 dp, кнопка
короны — с 40 до 36 dp. Радар с вложенным аватаром и никнейм подняты вместе
на 6 dp; на A35 этот подъём, расширение и уменьшение короны не применяются.
Изменения ограничены страницей «Поиск»; остальные вкладки не затронуты.

## Проверки кода и артефакта

- Полный frontend Jest: 168 наборов, 1603 теста PASS.
- Проверка классов телефонов после уточнения: 14 тестов PASS.
- Frontend TypeScript, ESLint изменённых файлов, `git diff --check`: PASS.
- Итоговый AAB: release 214 / 1.1.23. Контрольная сумма и проверки находятся
  в `results.json`; публикация в Google Play не выполнялась.

Скриншоты и исходные журналы: `/private/tmp/livi-media-214-20261122/`.
В этот отчёт не включены секреты установки, ключи файлов и личные сообщения.

Три временных аккаунта (два медиатеста и один настройки UI) удалены через
собственную аутентифицированную операцию удаления профиля.

По отдельной просьбе пользователя с A35 дополнительно удалены QA 211, QA 213 и
QA Native 213. На обоих телефонах из вариантов LiVi остались только
`com.kolt12max.livi` (релиз 213) и `com.kolt12max.livi.dev`; их данные сохранены.

Последняя корректировка 64 → 68 dp внесена после физической приёмки;
сохранённые скриншоты показывают предыдущие 64 dp. Повторная установка
проверочных приложений на устройства для этой небольшой правки не выполнялась.

Боковые поля нижней навигации в портрете приведены к полям «Онлайн»:
8 dp для больших телефонов класса S25 Ultra, 12 dp для A35. Та же величина
используется для ширины SVG-контура панели и реальных полей её контейнера.

Такие же поля в портрете применены к контейнерам фильтров в «Друзьях»,
«Чатах» и «Звонках»: 8 dp на больших телефонах и 12 dp на A35.
Поля списка сообщений/друзей/журнала звонков не изменялись.

Верхний правый куб пространственного фона смещён вправо и вверх, к кнопке
короны: на +80 / −28 px в сцене 1440×2578. Генерация без изменения параметров
сначала воспроизвела исходные шесть текстур с нулевой пиксельной разницей.
После переноса изменена только область верхнего куба, карты глубины и размытая
копия; фоновая подложка полностью совпала с прежней. На устройства для этой
правки проверочные сборки не устанавливались.

Последнее уточнение положения куба: ещё на 16 px влево и 12 px вниз
от предыдущего варианта (координаты сцены, не экранные dp).

На больших телефонах класса S25 Ultra кнопка «Найти собеседника» в портрете
дополнительно опущена на 4 dp. Смещается только контейнер кнопки, расчёт
положения радара и никнейма этим уточнением не меняется.

Исправлено появление кнопок сохранения/удаления никнейма после автосохранения
аватара: общий `savedToast` больше не открывает действия ника. Они показываются
при фокусе поля или несохранённом изменении никнейма. Регрессионные тесты
рендерят настоящую строку профиля: на старом коде воспроизвели ошибку после
успешного сохранения аватара и после потери фокуса без изменения ника.

На больших телефонах класса S25 Ultra фото на «Поиске» в портрете теперь
использует тот же расчёт диаметра, что и обычный «Профиль»: ширину окна,
физическую диагональ и общий масштаб 0.88. Размер внешнего диска и пунктирного
кольца радара не меняется; внутренний круг подгоняется под край фото.
Расчёты A35, планшетов и компактного landscape сохранены. Четыре регрессионных
сценария для ширины 360/384/411/432 dp проверяют равенство фото и неизменность
внешней геометрии радара. Повторная физическая приёмка этой правки не завершена.

При сохранении никнейма больше не загружается повторно локальное превью
уже сохранённого аватара. Загрузка фото выполняется при явном выборе нового
аватара; сохранение ника не запускает галочку на фото. Регрессионный тест
воспроизвёл повторный `user.uploadAvatar` на старом коде и проверяет его отсутствие,
сохранение нового ника и отсутствие события успешного сохранения аватара.
Отдельный тест строки профиля проверяет, что после сохранения справа остаётся
карандаш, а кнопки сохранения и удаления скрыты. Эти сценарии проверены
автоматически; никнейм пользовательского аккаунта на телефоне не изменялся.
