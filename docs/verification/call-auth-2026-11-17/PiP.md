# PiP: результат перед паузой, 17 ноября 2026

По просьбе пользователя после проверки PiP работа приостановлена, S25 разрешено отключить. Остальная программа hardening не завершена. Времена — МСК.

## Исправления

На A35 Android 17 системное окно оставалось с логотипом при продолжающих работать камере и аудиосервисе. Чтение состояния QA через JDWP без приостановки VM показало `frameReady=false` и видимый backdrop; на S25 было `true` и backdrop GONE.

1. Повторная установка video mode больше не обнуляет уже полученный clean-layout ACK. Реальный переход logo -> video по-прежнему требует нового ACK; logo-only готов сразу. Добавлены три Kotlin regression-теста. Эта правка сама по себе не устранила зависание A35; отрицательный прогон сохранён.
2. ACK использует существующую MainActivity, когда React currentActivity уже недоступна после onPause.
3. Применение `SystemPiPModeChanged` перенесено из `requestAnimationFrame` в microtask вне нативного callback. Подготовка compact video больше не зависит от следующего кадра анимации при уходе Activity в фон. Новое событие отменяет предыдущую отложенную операцию; unmount отменяет оставшуюся работу. Три новых теста проверяют выполнение без таймеров/кадров, enter -> exit и unmount.

После третьей правки на A35 `frameReady=true`, backdrop GONE, видео отображается. Пользователь подтвердил двустороннюю речь и движение изображения.

Сервер подтвердил те же два participant SID до/после всей матрицы — новый звонок для переходов не создавался. Эти признаки дополняют человеческую проверку слышимости, не заменяют её.

Автопроверки: frontend **141 suite / 1378 tests**, Kotlin **18 tests**, frontend typecheck, ESLint, release build и diff check — PASS. Backend ранее на том же исходном коде: 38 suites / 310 tests, шесть acceptance-сценариев PASS.

## Завершение и границы

Звонок завершён штатной кнопкой A35. На обоих телефонах проверены MODE_NORMAL, отсутствие активной камеры приложения, call services, LiVi wake locks и pinned window. Wi-Fi/mobile data = 1/1; настройки ориентации после предыдущих прогонов восстановлены. Два непрерывных logcat reader остановлены. Новые проверки после просьбы о паузе не запускаются.

Ранние снимки in-app -> system показывают интерфейс приложения до установившегося video-only capture. Длительность переходного кадра не измерена; отсутствие визуальных вспышек не объявлено доказанным. После удалённого завершения S25 снова оказался на MainActivity, хотя перед завершением запускались Settings; поведение фокуса требует отдельной диагностики. Повтор финального APK PiP с VPN выключенным на обоих устройствах отложен. Bluetooth-гарнитуры нет. Весь проект и все исторические ошибки не объявлены полностью проверенными.
