# S25 Ultra: смещение профиля после холодного запуска

24 ноября 2026, dev 215, Samsung S25 Ultra `R5GL550T4TB`. Сценарий: остановка процесса через `am force-stop`, запуск dev-клиента с Metro и нажатие «Профиль» сразу при появлении Home. Данные приложения не очищались.

## Причина и изменение

Профиль сначала рассчитывал раскладку через estimateHubPaneHeight, а затем заменял её результатом onLayout. Оценка вычитала устаревшую высоту панели и шапку, которой в хабе профиля нет. Для S25 с кнопками это 52 + 48 + 16 + 12 = 128 dp вместо фактических 66.5 + 48 = 114.5 dp. Первые строки получались ниже по высоте; при позднем замере они увеличивались, и прижатая к низу группа сдвигалась вверх.

Home теперь передаёт paneHeight из той же геометрии, которая задаёт padding панели: высота корня минус верхний inset и фактическая высота дока. Удалены отдельные оценки, отложенный onLayout и сохранённые по ориентациям замеры профиля. Первый кадр и последующие используют один размер. Нижний зазор, согласованный с пользователем, сохранён.

## Проверка

- До исправления проблема воспроизведена на записи: верх первой карточки меняется с y=408 до y=381 в видео 720×1560. Это 27 px видео, 54 px экрана 1440×3120 или 13.5 dp при плотности 4.
- После исправления проведены два отдельных запуска с остановкой процесса и ранним входом в профиль. Проверка декодированных кадров записи отслеживает верхнюю границу первой карточки при видимой строке удаления профиля. Результаты и число кадров записаны в results.json. Положение проверено на всех декодированных кадрах профиля, не только редких screenshots.
- Тесты profileHubLayout, nickname, welcomeRadarScene и welcomeTabBarLayout: 4 suites / 77 tests PASS. TypeScript, ESLint и git diff --check PASS.
- AAB/release APK 215 пересобраны; release source map сверена с 419 файлами проекта, Hermes в APK/AAB совпадает. Bundletool, AAB signature, APK signature и zipalign PASS.
- Правка JS доступна dev-клиентам через Metro. Нативный APK не менялся. Данная физическая приёмка относится к dev; отдельный холодный запуск оптимизированного release не выполнялся.

Локальные доказательства: `/private/tmp/livi-215-profile-cold-20261124/`: before.mp4, after.mp4, after-repeat.mp4, соответствующие logcat, события запуска и *-all-frames.json. Записи сняты в 720×1560; координаты экрана вдвое больше координат видео.

Эта правка устраняет изменение размеров профиля после его собственного onLayout. Она не исправляет ранее установленную ошибку времени жизни Promise в Skia и не подтверждает отсутствие иных проблем lifecycle.
