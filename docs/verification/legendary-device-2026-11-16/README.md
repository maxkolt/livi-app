# Legendary: проверка на Samsung A35, 16.11.2026

Проверка выполнена на подключённом Samsung A35, в настоящем приложении `com.kolt12max.livi.dev` с производственным API. Очистка оформления текущего профиля была явно разрешена пользователем.

## Окончательный интерфейс удаления

[Видео режима удаления](delete-mode-demo.mp4), [строка после свайпа](delete-mode.png), [подтверждение](delete-confirmation.png), [итоговая коллекция](final-collection.png).

- Свайп влево из середины строки открывает режим удаления. Превью, название и «Применить / Снять» плавно скрываются; их нельзя нажать, и они скрыты от экранного диктора.
- Остаётся круглая корзина диаметром 38 dp — немного больше высоты кнопки «Применить» (34 dp), по последнему уточнению пользователя. Иконка 20 dp, область нажатия расширена на 6 dp. Цвет обводки, заливка и реакция на нажатие взяты из общего `AppDialogButton` с вариантом `danger`.
- По всей строке проявляется слабый красный градиент и тонкая красная граница. Переход подсветки 160 мс, скрытие содержимого 120 мс.
- Нажатие корзины закрывает свайп и открывает подтверждение. Отмена сохраняет оформление. Нажатие свободного места открытой строки возвращает обычный вид. Одновременно раскрывается одна строка.
- На устройстве проверены открытие, подтверждение, отмена и восстановление строки. Последний подарочный фон намеренно не удалялся повторно.

## Очистка и получение оформления

Через настоящий интерфейс удалены три рамки (`fire`, `frost`, `diamond`) и два фона (`aurora-chat`, `deep-space`). [Пустая коллекция](empty-collection.png) подтверждена серверным состоянием. Другие данные профиля и другие аккаунты не очищались.

Затем отправлен внутренний тестовый отзыв, получен одноразовый подарок, выбран фон «Неон» (`aurora-chat`). Проверены снятие, применение и сохранение после полного перезапуска приложения. Итог: один активный фон «Неон», рамок нет, баланс 0, подарок использован. [Итоговый ответ API](final-state.json).

## Цвета, мерцание и скорость

Интерфейс наград использует общие голубовато-серые цвета Поиска: `UI_ACCENT`, `UI_ACCENT_LIGHT`, `UI_SURFACE`, `UI_RIM`, `UI_ACCENT_SOFT`. [Внешний вид](legendary-radar-colors.png), [запись открытий](legendary-opening.mp4). Цвета самих продаваемых рамок и изображений фонов сохранены.

Карусели Legendary переведены на нативный `Animated.FlatList`, с готовой начальной позицией и ожиданием изображений перед показом. Магазин прогревается после заставки; ожидание `InteractionManager` ограничено 500 мс, поскольку фон главного экрана постоянно анимируется. Одинаковые ответы API не вызывают повторную смену обоев. Скрытый магазин не запускает анимации; карточки мемоизированы, окно виртуализации уменьшено.

В записи открытий проверены 647 кадров, 233 кадра с магазином, три сегмента показа; пустых центральных превью не обнаружено. [Результат анализа](opening-frame-analysis.json). Это ограниченная проверка конкретной записи, а не гарантия отсутствия любого мерцания на всех устройствах.

Измерения настоящих запросов: снятие/применение фона 153/138 мс, отправка отзыва 160 мс, получение подарка 216 мс. После устранения ожидания рассылки друзьям повторный запрос удаления рамки занял 363 мс. Сетевая задержка не равна полной задержке перехода экрана. [Измерения применения](apply-timings.json).

## Старые платёжные подключения

Удалены интеграции IntellectMoney и ЮKassa: запросы к сервисам, checkout HTML/виджет, проверка оплаты, возврат в приложение, обработчики вебхуков, модели заказов, цены в рублях, примеры настроек и инструкция подключения. В интерфейсе удалены неиспользуемые тексты оплаты. Отдельных зависимостей этих сервисов в package.json не было.

Старые платёжные адреса оставлены только как ответ `410 {ok:false,error:"use_livi_points"}` для старых версий приложения. Они не загружают провайдеров, не обращаются к магазинам и не выдают оформление. Сохранённые ранее права на оформление не удаляются автоматически. История заказов в базе не очищалась.

Backend `b96693b683129331ae41014b936981581609c76b` развёрнут на сервере, 248 файлов сверены по SHA-256, расхождений нет. Удалены восемь устаревших исходных/конфигурационных файлов; новая папка dist собрана с нуля. Из серверного .env удалены семь платёжных настроек; остальные строки и зависимости сохранены. Настроек оплаты в systemd не обнаружено. Локальный .env тоже не содержит старых платёжных параметров и не добавлен в Git.

После обновления публичный `/health`: HTTP 200, Mongo=1, Redis ready, Socket.IO Redis adapter=true. Все шесть проверенных старых платёжных адресов возвращают HTTP 410. Сервис active/running, NRestarts=0. До перезапуска: 0 участников, 0 очередей, 0 пар. [Результат развёртывания и резервная копия](backend-deployment.json). Окончательные изменения размера/подсветки затрагивают только frontend; backend совпадает с этой версией.

## Проверки и ограничения

Полный frontend: 130 наборов, 1313 тестов. Полный backend с изолированной локальной MongoDB: 31 набор, 265 тестов, в том числе 34 сценария наград/удаления/отключённых платежей. После последнего изменения оформления: 11 профильных тестов, TypeScript, ESLint и production Android export прошли. Backend build также прошёл. [Вывод проверок](checks.txt).

Первый общий запуск backend-тестов в ограниченной среде не смог открыть локальные HTTP-серверы; полный повтор с разрешёнными локальными соединениями прошёл. Подключение к базе из .env автопроверка не разрешила; вместо него использована MongoDB 127.0.0.1 в уникальной временной базе.

Во время обновлений кода в работающем dev-клиенте зафиксированы нативные падения Skia в `JsiPromises / fromURI`. На свежем запуске без изменения кода окончательный сценарий прошёл. Причина этого сбоя горячей перезагрузки здесь не устранена; эту проверку нельзя считать доказательством стабильности release-сборки. APK/AAB в магазины не публиковались. Существующее ограничение показа Legendary через `__DEV__` сохранено. Отдельный сценарий на втором устройстве и матрица VPN в этой проверке не выполнялись.

## Повторные свайпы: исправление 17.11

После пользовательской проверки воспроизведён дефект: `ReanimatedSwipeable` переставал принимать повторный свайп. Вместо сдвигаемого содержимого постоянный `Gesture.Pan` теперь закреплён на всей строке; скрываемые элементы не участвуют в области распознавания жеста. Свайп влево открывает удаление, вправо закрывает; вертикальный жест остаётся прокрутке. Короткое движение не переключает режим.

На A35 проверены четыре открытия/закрытия подряд без навигации и перезапуска: [четвёртое открытие](repeated-swipe-open.png), [четвёртое закрытие](repeated-swipe-close.png). [Запись повторных свайпов и отмены подтверждения](repeated-swipes.mp4). Единственный фон «Неон» остался активным. Автотест выполняет восемь циклов, закрытие нажатием, программное закрытие и повторное открытие. Полный frontend: 130 наборов, 1313 тестов; TypeScript, ESLint и Android production export прошли.

Размеры аватара по реально отрисованным компонентам A35: Профиль 137 dp, Поиск 138 dp. Разница 1 dp вызвана отдельными коэффициентами профиля и подгонкой фото к внутренней окружности радара; размеры в этом исправлении не менялись.
