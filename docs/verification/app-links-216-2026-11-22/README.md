# Окончательный App Links релиз 216 / 1.1.25

22 ноября 2026, Москва. Эта сборка заменяет ранее подготовленный AAB 215.
**Загрузка в Google Play и результат Console после загрузки не подтверждены.**

Сохранены исправления [предыдущей проверки](../app-links-215-2026-11-22/README.md):
один публичный HTTPS-фильтр приглашений, отсутствие шести публичных custom
schemes, debug-схемы Expo в debug-манифесте, опубликованная совместимая с прежними
Play-версиями страница приглашения и именованные импорты React Native.

## Дополнительное исправление маршрутизации

Прежний App.tsx искал `livi://...` в любом месте полученного URL. Например,
`https://api.liviapp.com/invite/<code>?next=livi://cancel-outgoing&callId=<id>`
попадал в ветку команды звонка. Теперь `utils/deepLinks.ts` разбирает сам URI:

- Команды звонка принимаются только для точного `livi://<command>` с нужными
  параметрами. Сохранены `callId`/`call_id`, `from`/`userId`, декодирование имени,
  необязательный завершающий `/` и регистр команды. Само выполнение действий
  принятия/отклонения/отмены звонка не переписывалось.
- Приглашения принимаются для точного HTTPS-домена `api.liviapp.com` и корректного
  кода. Legacy `livi://invite/...` сохраняется для iOS/debug.
- Чужие домены, похожие имена хоста, вложенные адреса, неверные пути и URI
  разработчика не превращаются в приглашения или команды звонка.

Выбран следующий номер 216, чтобы его можно было загрузить независимо от того,
успел ли пользователь отправить ранее выданный 215.

## Физическая проверка A35

Dev-приложение обновлено через `adb install -r` до 216 с сохранением данных;
установленная Play-версия не менялась. После загрузки проекта в dev client четыре
тестовых HTTPS-URL с вложенными `incoming-call`, `answer-call`, `decline-call`,
`cancel-outgoing` доставлены в MainActivity. У всех URI заведомо неверный код
приглашения и фиктивные идентификаторы; реальные звонки и сообщения не отправлялись.

Ни один URL не вызвал обработчик звонка. До и после проверки оставался тот же
Home/Search. В логе процесса: 0 TypeError / ReferenceError / Invariant Violation
и 0 трёх предупреждений React Native.

Проверка существующего чата, фото, полноэкранного просмотра и системного меню
«Поделиться» выполнена на 215; эти медиа-компоненты исправлением 216 не менялись.
Разговор двух телефонов, звук/видео в обе стороны, VPN on/off, физическая свежая
установка из Play с приглашением и iOS после этой правки не проверялись.
