## Изменения

- В основном AndroidManifest оставлен один публичный VIEW/BROWSABLE-фильтр:
  `https://api.liviapp.com/invite/`, `autoVerify=true`.
- `livi` и `exp+livi-video-chat` перенесены в `src/debug/AndroidManifest.xml`.
  Production Expo config не содержит общей пользовательской схемы; автоматическое
  добавление Expo-схемы отключено. iOS сохраняет `livi`.
- Внутренние обработчики принятия/отклонения/отмены звонков не переписывались.
  Нативные уведомления используют явные компоненты; HTTP-fallback отклонения
  также явно адресует MainActivity. Для внутренних explicit intents публичный
  BROWSABLE-фильтр не требуется.
- Android-ветка страницы приглашения теперь использует package-scoped intent с
  HTTPS-доменом и `/invite/`. Этот путь уже поддерживается установленной
  Play-версией 213 и предыдущим манифестом 214. Сохранены Install Referrer,
  clipboard fallback, ручное повторное открытие и iOS-ветка. Исключён повторный
  переход браузера на ту же HTTPS-страницу по таймеру.
- Три `await import('react-native')` заменены именованными импортами
  `NativeModules` и `Share`. Это убирает обход всех экспортов Metro, вызывавший
  предупреждения ProgressBarAndroid / Clipboard / PushNotificationIOS.
- Версия повышена до 215 / 1.1.24, поскольку 214 уже присутствует в Play Console.

Обычные ссылки, которыми делится интерфейс LiVi, остаются HTTPS-приглашениями.
Публичное Android-открытие вручную составленных `livi://...` URL в новом релизе
больше не регистрируется. Внутренние явные переходы и debug-схемы сохранены.

## Телефон Samsung A35

Debug-приложение обновлено до 215 через `adb install -r`; данные сохранились.
Проверены запуск, открытие через Expo-схему после восстановления USB reverse 8081,
существующая переписка, фото в полноэкранном просмотрщике и системное меню
«Поделиться». Меню закрыто без отправки. Явный внутренний VIEW-intent без callId
доставлен в MainActivity без вмешательства в настоящий звонок.

В логе нового процесса после медиа-проверки: **0** указанных deprecation warnings,
**0** TypeError / ReferenceError / Invariant Violation.

Установленная Play-версия 213 осталась на месте. `pm get-app-links` возвращает
`api.liviapp.com: verified`, разрешение link handling включено. Package-scoped
HTTPS resolve выбирает MainActivity, чужой домен с ограничением на пакет не
разрешается. Неограниченный shell resolve вернул ResolverActivity, поэтому его
результат не используется как доказательство автоматического перехода из браузера.

Не проводились: реальный разговор двух телефонов, проверка звука/видео в обе
стороны, VPN on/off, физическая свежая установка из Play с приглашением и iOS.
Успешные unit tests и открытие фото не заменяют эти сценарии.
